# SentryGate — Roadmap (future)

The **door build** in this repo ships RFID, keypad PIN, temp PIN, remote OPEN, and SoftAP provision. Items below are **not implemented** here — planned or exploratory only.

| Feature | Description |
|---------|-------------|
| **BLE** | Proximity unlock / mobile credential over Bluetooth Low Energy |
| **NFC Wallet** | Apple Wallet / Google Wallet tap-to-unlock |
| **QR-CAM** | Camera-based QR scan for visitor or one-time codes |
| **Biometric** | Fingerprint or face match at the reader |
| **GSM** | SMS/call fallback alerts and remote commands without Wi‑Fi |
| **Flutter app** | Cross-platform field/operator mobile client |
| **Visitor CRM** | Guest invites, schedules, audit trail, reception workflows |

For current door scope and architecture, see [ARCHITECTURE.md](ARCHITECTURE.md) and [README.md](../README.md).
